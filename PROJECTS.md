# Portfolio plan (0-2 yrs → 1L+/month)

For "builds and ships fast with AI" roles, hiring managers want **live, used, shipped products**, not tutorials. Ship 3, finish them, put them live with real users and a short write-up on each.

1. **This job engine, open-sourced** — meta and relevant: agents, LLM scoring, Playwright, a clear safety design. Write a build-in-public thread about it.
2. **A real SaaS shipped in ~1 week** — Next.js + Postgres + Claude API + Stripe/Razorpay, deployed on Vercel, with a few actual users. Pick a painful niche problem (e.g. an AI tool for Indian small businesses/CAs/clinics).
3. **An AI agent product with evals** — e.g. a support/research agent with tool use, a small eval suite and cost/latency numbers. Shows you understand reliability, not just demos.
4. (Optional) **A Claude Code/MCP tool or plugin** other devs use — stars and installs are strong proof.

Each project needs: live URL, demo video (60s), README with architecture + metrics, and one line on your resume with a number (users, time-to-ship, cost).

## Where to apply
YC Work at a Startup, Wellfound, HN Who's Hiring, X/Twitter hiring posts, Ashby/Greenhouse boards of AI startups, and direct founder DMs. For 1L+ target funded startups and remote-international roles.
